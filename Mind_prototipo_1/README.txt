# Mind — Protótipo funcional

Abra `index.html` no navegador.

O protótipo simula:
- login com diferentes usuários;
- níveis Consultor, Gestor e Líder;
- áreas organizacionais;
- feed com regras de visibilidade;
- pessoas visíveis conforme hierarquia;
- base de conhecimento;
- estrutura organizacional;
- publicação de conhecimentos.

Este é um MVP front-end: os dados ficam no JavaScript e não existe servidor/banco de dados real ainda.
